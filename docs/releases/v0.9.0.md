# LMBY v0.9.0 —— 1.0 之前的最后一个版本

LMBY 是**纯 Web 在线播放**的轻量自托管媒体服务器：浏览器是唯一客户端，HTTP 是唯一出口，
一个 Go 二进制（前端 `go:embed` 进去）+ PostgreSQL，**运行期零 Node**，AGPL-3.0。

> 这一版是 **1.0 之前的最后一个版本**：功能上就是 v0.3.x 那一批（直播电视 / 界面完整化 /
> 用户与权限），区别在于把**交付面**收拾干净了 —— 界面上不再出现解释性文字与内部术语，
> 仓库里也不再带开发过程文档与验收脚手架。装上它，你看到的就是一个产品，不是一份开发笔记。

## 一、这一版的重点：交付面

**界面**：去掉了解释性文字，只留控件、状态与错误信息。

- 删掉 30 段说明性段落（原先很多页面顶部都有一整段「为什么这么做」）；
- 15 处长篇机制解释压成一句事实（播放决策、字段锁定、只读库、推荐口径…）；
- 清掉界面上的**里程碑代号与内部黑话**：页脚的里程碑标记、库页的「M2 / M5」、
  设置页的「M6 搬到了这里」，以及 `overlay` / `ffprobe` 这类实现细节；
- 英文界面同步更新。

**仓库**：只留交付需要的东西。

- 保留：源码、`README.md`、`CHANGELOG.md`、`docs/ADR`、`docs/TRANSCODING.md`、
  `docs/images`（截图）、`docs/releases`（逐版说明）、`deploy/`、`migrations/`；

## 二、功能一览

**直播电视**

- 直播源：粘贴 / 上传 / 订阅地址导入；按各自间隔自动刷新（可关）；按地址增量更新，
  **不覆盖你的用户态**（停用、收藏、探测结果）；删源不删频道。
- 频道探测：真连一次源站（与播放共用同一套输入参数），写出人话摘要与「通 / 失效」标记；
  探测前先确认探测工具可用，不可用就一条结果都不写。
- 播放：同一频道所有观众**共享一路 ffmpeg**；1 秒分片（实例实测起播 0.6~1.8 秒）；
  浏览器解不开的源编码自动转码。
- 前台只列「能用能看的」频道；**起播失败会自动重新探测一次**，源站真的挂了就把它从前台收起来。
- 外链：给外部播放器的签名地址（带有效期），不需要登录。

**界面**

- 首页：大屏轮播 + 继续观看 + 我的收藏 + 为你推荐（按观看历史做流派画像）+ 评分最高 + 最近添加。
- 搜索：中文按二元组切词、英文按整词、容忍错字；结果分面（类型 / 媒体库 / 流派 / 演职员）+ 即时联想。
- 详情页：剧集 → 季 → 集、演职员、相关推荐；海报墙按库浏览。
- 播放器：多音轨 / 多字幕（ASS 走 libass 保留特效、文本走原生轨道、图形字幕按需烧录）、
  画质档、从上次位置续播。
- 我的列表（收藏 / 播放列表 / 合集）、个人中心（显示名、口令、外观、设备会话）。
- 中文 / English 双语；手机可用。
- 只读媒体库：刮削产物写在数据目录，**不写你的媒体目录**。
- 设置：媒体库管理、人工匹配、会话、直播源、用户（都收在「设置」里）。

**用户与权限**

- 库级可见性白名单；`允许转码`、`允许直播`、并发播放上限；
- 改口令 / 禁用 / 收紧库范围 → **立刻吊销该用户的全部会话**；
- 硬规则：不能修改自己的管理员与禁用位，也不能禁用 / 降级 / 删除**最后一个管理员**。

## 三、从 v0.3.1 以来修掉的问题

- **新建媒体库直接失败（500）**：建库那条语句的列与扫描目标不匹配（后来加的 `readonly`
  列没跟上）。之所以长期没被发现，是因为验收只测「改现成媒体库」而没人真的建过库 ——
  现在这条路径有专门的验收。
- **管理面「会话」页的直播会话列表为空**：解析会话键时没跟上「转封装 / 转码各自一路」的
  新格式，那条记录被静默跳过（不报错）。只影响会话列表显示，起播、共享、切台都不受影响。

## 五、已知限制

- **Safari / iOS**：原生 HLS / HEVC / WebVTT 的旁路代码就位，但**没有真机验证**。
- **直播**：失效源按探测快照判定（起播失败会自动重探一次，但源站变坏总要先失败一次才被发现）；
  没有回看 / 时移；没有 EPG / 录制。
- 1 秒分片让请求数翻倍，弱网下表现未测。
- **外链分享的限次数 / 限有效期**、**审计日志**、**家长分级**、个人中心的字幕与音轨偏好尚未做。
- 没有内置 TLS：要给家庭网络外访问请自己加反向代理。
- 图片 / 元数据不写回媒体目录（只读库用数据目录存放），这是有意设计。
- Windows / macOS 上不节流（无法暂停进程，优雅降级为「不节流」）。

## 六、快速开始

需要 PostgreSQL 与服务端 `ffmpeg` / `ffprobe`；配置放 `/etc/lmby/config.toml`，
systemd 单元与示例配置见 `deploy/`。Docker 方式与手动部署步骤见 `README.md`。

**Assets**：`lmby-linux-amd64` / `lmby-linux-arm64` / `lmby-linux-armv7` / `lmby-windows-amd64.exe`，
以及 `SHA256SUMS.txt`（`sha256sum -c SHA256SUMS.txt` 校验）。

逐版说明见 [`CHANGELOG.md`](../CHANGELOG.md)。
