# LMBY v1.1.0 —— 接入社区元数据库 KeqDB

这一版最大的变化是**元数据可以来自社区的公共库**：打开设置里的开关，KeqDB 会
**优先于 TMDB** 提供影片资料；同时你也能把自己库里整理好的数据**贡献回去**。
另外新增了「观看统计」页面，播放页在下载字幕字体时会显示进度。

> 本版**没有数据库迁移**，也没有破坏性的配置改动：装上二进制重启即可。
> 新增的两项配置（是否加入、实例 token）都在「设置 → 元数据与服务状态」里点，
> 不需要改配置文件。

---

## 一、元数据共享：接入 KeqDB

KeqDB 是一套社区维护的影视元数据库，接口与 TMDB v3 同形。本版做了三件事：

**1）取数优先用它。** 在设置里勾上「加入元数据共享改进计划」后，**刮削取数**
与**人工匹配搜索**都会先问 KeqDB，它没有（或出错）再回退 TMDB。关掉开关就
完全不用它 —— 开关**立即生效，不用重启**。

**2）可以贡献回去。** 条目详情页多了一个「贡献到 KeqDB」按钮（只对管理员显示）：
点了就把这部剧/这部电影的资料提交过去。几点说明：

- 剧集会**把整部剧的季与集一起带上**（不会只传一集）；
- 类型按 TMDB 的类型编号提交，认不出的自定义标签（如「日韩」「萌系」）
  作为关键词提交，不会硬塞进类型里；
- 提交进的是 KeqDB 的**待审队列**，由那边管理员审核后才进公开库。

**3）实例 token。** 贡献需要一个实例级 token，在设置里填（形如 `keq_…`，
由 KeqDB 后台签发）。它是**加密存放在本机数据库**里的，界面上**不会回显**，
也不会写进日志。

## 二、观看统计（新）

设置里多了一页「观看统计」，数据来自每个人的播放进度：

- **总览**：总播放次数 / 被看过的影片数 / 看过的用户数；
- **看得最多的影片**：**按整剧聚合**（一部剧的所有集加起来算一部），点进去是剧的详情页；
- **看得最多的用户**：播放次数与看过的影片数；
- **谁看了什么**：明细表（用户 · 影片 · 次数 · 进度 · 最后观看），可按用户筛选、分页。

## 三、播放页：资源下载进度（新）

看 ASS 特效字幕前要先把**中文字幕字体**（约 20 MB）下载到浏览器。以前这段时间
界面上没有任何提示，看着像卡住了。本版在播放页底部加了一条进度条：

- **只在真在下载时出现**，下完自动消失；
- 显示百分比，不会倒退；
- 不额外增加流量 —— 字体本来就要下一次，只是把这次变得看得见。

## 四、内封字幕：等待不再悄悄超时

内封（封装在视频里的）字幕必须**把整个文件读一遍**才能抽出来。当文件在网络盘上时，
一部 500 MB 的剧集可能要几十分钟。而前端以前只等 70 秒就放弃 —— 用户看到的是
「点了字幕，转半天，然后什么都没有」。

本版把等待预算提到与服务端一致（20 分钟），并在等待期间显示**已等待的秒数**，
让它变成一个"正在做的事"而不是"看起来坏了"。

## 五、验收（真跑）

| 场景 | 结果 |
|---|---|
| KeqDB 作为取数源 | 开关打开后触发刮削与匹配搜索，服务端缓存里出现 `provider=keqdb` 的条目（与 `tmdb` 分开），数据来自 KeqDB |
| 开关关闭 | 完全不走 KeqDB（缓存里不再新增 keqdb 条目） |
| 贡献组装 | `?dryRun=1` 输出的人工核对：作品类型、季集层级（带首播日期）、演职员（带 `personId` / 角色 / 排序）、类型编号映射 |
| 贡献链路 | 用无效 token 提交 → KeqDB 明确返回「拒绝 token」（说明请求确实到达对方并完成鉴权） |
| 观看统计 | 真实库上返回：总次数 40 / 影片 13 / 用户 2；排行按整剧聚合正确（同一部剧的多集合并） |
| 下载进度条 | 无头浏览器（限速）实测：`0% → 100%` 单调推进，完成后进度条消失、字幕渲染器就绪 |
| 前端 / 后端 | `tsc --noEmit`、前端构建、`go build`、`go vet`、`go test ./...`、i18n 覆盖率 100% 全绿 |

## 六、说明

- 共享是**自愿**的：默认关闭，随时可以关掉；关掉后立刻不再向 KeqDB 取数，
  也不会再提交任何数据。
- 「贡献」目前是**手动**的（在详情页点按钮）。「开关打开之后新入库的内容自动贡献」
  还在路上，会在后续版本补上 —— 届时同样只作用于**新入库**的条目，不会翻旧账。
- 如果你的 TMDB 凭据从来没配过，本版之后**也可以正常刮削**了：只要共享开关打开，
  KeqDB 就能单独作为元数据源（此前这种情况会被"未配置元数据源"挡住）。
